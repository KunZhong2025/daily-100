## 豆包的体验，内网的环境

想要的效果：按住快捷键说话，松手，去完口头禅、补好标点的文字直接打进光标处——豆包语音输入法就是这个体验。我想把这份体验带到单位内网的一台 Windows 10 上：出不了外网，内网里只有 DeepSeek、GLM 这类文本大模型 API。

跟 ChatGPT 磨了几轮，落成一份部署指南，这篇是它的整理版。

## 先想清楚：语音输入是两截，不是一截

调研第一课，也是整件事最关键的认知。语音输入不是一个模型的事，是两截：

- **ASR（语音识别）**：声音 → 文字
- **LLM（大语言模型）**：文字 → 整理过的文字

DeepSeek、GLM 的 API Key 只吃文本，麦克风采进来的音频是喂不进去的。所以「内网只有文本大模型」不等于「语音输入做不了」，只等于 **ASR 这一截必须自己解决**——好在本地方案是现成的。

整条链路：

```
麦克风 → 本地 ASR → 内网 LLM（去口头禅、补标点、润色）→ 当前光标
```

想通这一点，选型就清楚了：ASR 要一个能本地跑的，LLM 走现成的内网 API。

## 按现实条件选型

条件：Windows 10 x64、没有独立显卡、不连外网、只有内网文本 API、不想搭服务器。

- 输入工具选 **SayIt**：全局快捷键录音、自动打进当前光标，中文界面，「AI 供应商」走 OpenAI 兼容接口，内网地址直接填
- 识别模型选 **SenseVoice Small**：CPU 就能跑，文件 253 MB、运行内存约 350 MB，FunASR 基准里比 Fun-ASR Nano 快约 4.8 倍、中文错误率还略低
- 量化版本选 **Q8_0**：错误率和全精度持平，又是 SayIt 官方默认版本，下载、校验、加载的流程都是现成的

## 具体步骤

![](assets/3.png)

### 一、备齐三个文件

在外网电脑下载，按单位允许的方式带进内网：

```text
SayIt_0.2.2_x64-setup.exe                      安装包
SenseVoiceSmall-Q8_0.gguf                      模型 253 MB（先核对 SHA-256）
MicrosoftEdgeWebView2RuntimeInstallerX64.exe   运行库（系统已有可跳过）
```

### 二、装软件，先切本地模式

双击装 SayIt；启动失败多半是缺 WebView2，装上再重启。**首次打开不要用默认的公共服务器模式**，第一件事去「语音引擎」切成本地模式（Local）。

### 三、放模型（最关键的一步）

在本地模式里选 SenseVoice Small，计算设备选 CPU。打开 SayIt 自带的「离线下载 / 手动下载指引」，照它给的目录和文件名，把 gguf 放到准确位置；想放 D 盘就先改存储位置，再按指引放。

**不要改名，不要随手丢文件夹**——模型一直显示「未下载」，九成是位置或文件名不对。放完重启，能成功加载才算过。

### 四、先测纯离线

先关掉「AI 整理」（大模型润色的开关），打开记事本，按快捷键录音说一句「今天上午我们整理了相关工作材料」，松手等上屏；成了再测一段 10～20 秒的口述。**这一步不成功，先不要配 DeepSeek。**

### 五、再连内网 DeepSeek

「AI 供应商」→ 添加 OpenAI 兼容服务，按内网网关的实际信息填三项：API Base URL（带不带 /v1 以接口文档为准）、API Key、模型 ID（照抄网关提供的，不要猜）。测试连接通过后开启 AI 整理，Prompt 用精简版：

```text
你是中文语音输入整理助手。删除嗯、啊等无意义口头禅；修正明显的识别错误；添加标点，适当分段。严格保留原意、数字、姓名、时间及专业术语。不推测、不补充事实。只输出整理后的文字。
```

## 上线前的检查

- 断网能打开 SayIt，模型显示已安装、CPU 能加载
- 关 AI 整理：记事本离线录音、识别、自动上屏全通
- 开 AI 整理：只连内网 API，整理后的文字正常上屏
- 重启电脑，不用重新下载模型

排查口诀：启动空白查 WebView2；模型「未下载」查位置和文件名；开 AI 后失败查内网地址、Key、模型 ID。

安全设置：历史记录、上下文感知、自动更新都关掉，网络只放行内网 API。

## 小结

- 语音输入是两截：本地 ASR 管听，内网 LLM 管润色，只有文本 API 也能攒出豆包体验
- 流程就五步：三件套进内网 → 切本地模式 → 按指引放模型 → 先测纯离线 → 再连 DeepSeek
- 不需要 Docker、WSL2、Python，也不需要 GPU——一台普通 Windows 10 就够
